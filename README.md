
# ThreatWatch-AI-Crowd-Monitoring-and-Weapon-Detection-System
ThreatWatch AI an AI-powered real-time surveillance system that focuses equally on crowd detection and weapon detection using computer vision and deep learning techniques. The system analyzes live video streams or recorded footage to monitor crowd density, detect the presence of weapons, and identify potential security threats in public spaces.

🧠 Key Features
--------------------
🧍 Real-time crowd detection
📊 Crowd density analysis
🔫 Weapon detection using deep learning models-
📹 Live video and recorded footage processing
⚠️ Threat and overcrowding alert mechanism
⚡ High-speed detection using YOLO architecture
🧠 Pre-trained deep learning model (.h5) integration

🛠 Technologies Used
---------------------
Programming Language: Python
Libraries & Frameworks:
OpenCV
NumPy
TensorFlow / Keras
Object Detection: YOLOv3
Deep Learning: CNN-based trained model (.h5)
Computer Vision: Real-time video analytics

📌 System Requirements
-----------------------
Python 3.7 or higher
Webcam or CCTV / video input
Pre-trained weapon detection model (modelnew.h5)
YOLO configuration file

🗂 Project Structure
---------------------
Crowd-Intel/
│
├── main.py                 # Main execution file
├── modelnew.h5             # Trained weapon detection model
├── yolov3_testing.cfg      # YOLO configuration for object detection
